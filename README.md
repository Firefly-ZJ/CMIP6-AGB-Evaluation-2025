# CMIP6-AGB-Evaluation

Code and Data for:
**Evaluation of vegetation above-ground biomass carbon from CMIP6 ESMs using global satellite-based estimates**
by *Zhang et al.*

## Introduction

We conducted a comprehensive evaluation of forest above-ground biomass carbon (AGC) simulations from 30 CMIP6 Earth System Models (ESMs) under historic scenario. The ESA CCI Biomass dataset was used as the reference data.

CMIP6 MME over-estimates global forest AGC by approximately 14% relative to CCI Biomass, with substantial inter-model and regional variation.
These discrepancies are strongly associated with canopy height and local hydrothermal conditions, while process diagnostics suggest potential shortcomings in simulated biomass–productivity relationships and carbon turnover.
